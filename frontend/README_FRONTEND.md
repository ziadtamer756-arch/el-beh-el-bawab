# دليل فريق الواجهة الأمامية (Frontend Team Guide - v2.0 Complete) 🎨📱

تم استكمال جميع الأجزاء البرمجية والتفاعلية في هذا المجلد، مع دعم وضع التشغيل المزدوج (**Hybrid Mode**):
- إذا كان سيرفر البايثون (`http://localhost:8000`) يعمل، يتصل التطبيق تلقائياً بالـ Backend الحقيقي.
- إذا تم فتح `frontend/index.html` مباشرة بدون تشغيل السيرفر، يعمل المحاكي المدمج (In-Memory Fallback Store) بنفس البيانات التجريبية حتى يتمكن أي فرد من الفريق من معاينة وتعديل جميع الشاشات فوراً!

## الشاشات المكتملة داخل التطبيق:
1. **واجهة الساكن (Resident Hub):** إرسال طلب جديد، تحديد الأولوية (عادي / مستعجل / بموعد)، متابعة خط سير الطلب، تسديد الحساب، وتقييم البواب بعد الاستلام.
2. **واجهة البيه البواب (Bawab Command Center):** التبديل بين (متاح الآن / مشغول خارج العمارة)، استقبال الطلبات مرتبة حسب الأولوية، إدخال التكلفة الفعلية للمشتريات من الفاتورة، وتحويل الحالة إلى «تم التوصيل».
3. **شاشة محفظة الإكراميات وحساب العهدة (Wallet & Custody Ledger):** متابعة إجمالي إكراميات عم عبد السميع، فواتير المشتريات غير المسددة، وتحصلات صيانة العمارة الشهرية.
4. **لوحة إعلانات العمارة ودليل السكان (Announcements & Directory):** نشر تنبيهات السكان (مثل صيانة الأسانسير أو تنظيف الخزان) واستعراض شقق العمارة.
5. **بوابة الدخول السريع وتبديل الحسابات (Quick Auth & Role Switcher):** التبديل الفوري بين حساب البواب أو أي ساكن أو تسجيل ساكن جديد بكود العمارة `NILE-15`.
