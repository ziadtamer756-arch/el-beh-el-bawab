# 🤖 دليل وكلاء الذكاء الاصطناعي (AI Agents Architecture)

مشروع **«البيه البواب»** مدعوم بمحرك ذكاء اصطناعي متقدم يعمل بنموذج **`openai/gpt-oss-20b`** عبر منصة **Groq API** فائقة السرعة، ومصمم خصيصاً للتعامل مع اللهجة المصرية العامية بكفاءة ودقة.

---

## 📁 هيكل ملفات الذكاء الاصطناعي

```text
├── ai/                              <-- مجلد الـ AI الرئيسي
│   ├── __init__.py                  # تصدير دوال ومحركات الـ AI
│   ├── test_ai.py                   # اسكريبت فحص اتصال Groq واختبار المحادثة الحية
│   └── README_AI.md                 # التوثيق الشامل لنظام الذكاء الاصطناعي
│
└── backend/app/ai/                  <-- حزمة الـ AI البرمجية للباك إند
    ├── __init__.py                  # نقطة الدخول لحزمة الـ AI
    ├── groq_agent.py                # وكيل Groq الحقيقي (Agent 01 - Order Parser)
    ├── ai_agents_engine.py          # كتالوج ومحرك الـ 15 AI Agents
    └── prompts.py                   # التعليمات والتوجيهات (System Prompts) والشخصيات
```

---

## ⚡ كيف يتصل الشات في الموقع بالذكاء الاصطناعي؟

1. **المستخدم (البيه الساكن)** يفتح الشات في الموقع ويكتب أي طلب بالعامية المصرية (مثلاً: *«عم عبد السميع هاتلي ٢ لبن جهينة و١٠ عيش سخن بسرعة»*).
2. المتصفح يرسل طلب `POST` مباشر إلى مسار السيرفر:
   ```http
   POST http://localhost:8000/api/ai-agents/chat
   Content-Type: application/json

   {
     "message": "عم عبد السميع هاتلي ٢ لبن جهينة و١٠ عيش سخن بسرعة",
     "building_id": 1,
     "resident_id": 2
   }
   ```
3. يستقبل السيرفر الطلب في `backend/app/routers/ai_agents.py` ويمرره إلى:
   `app.ai.groq_agent.run_groq_order_parser_agent`
4. يتصل الوكيل مباشرة بـ **Groq API** باستخدام الموديل المحدد في `.env` (`openai/gpt-oss-20b`) عبر مكتبة `OpenAI` الرسمية.
5. يرجع الـ AI استجابة ذكية مهيكلة (JSON) تحتوي على:
   - **الرد الحواري بالمصري:** *«يا مرحب يا باشا! عنيا ليك، هجيبلك اللبن والعيش فوراً...»*
   - **الأصناف المستخرجة:** `لبن جهينة (٢ لتر)`، `عيش سخن (١٠ رغيف)`
   - **التكلفة التقديرية:** `104 ج.م`
   - **الإكرامية المقترحة:** `20 ج.م`
   - **درجة الاستعجال:** `urgent` (نظراً لكلمة "بسرعة")
6. يقوم الشات في الفرونت إند برسم بطاقة طلب تفاعلية مباشرة تتيح للساكن بضغطة زر واحدة: **«🚀 اعتماد وإرسال هذا الطلب فوراً لعم عبد السميع»**.

## 🧪 طريقة اختبار الاتصال بالـ AI

من التيرمينال، يمكنك تشغيل الاسكريبت بأي من الأمرين:

```powershell
python test_ai.py
# أو
python ai/test_ai.py
```

## 🚀 تشغيل النظام كاملاً

1. تشغيل السيرفر:
   ```powershell
   python run.py
   ```
2. فتح صفحة الموقع:
   افتح `frontend/index.html` أو `index.html` في المتصفح وابدأ الدردشة مباشرة مع «عم عبد السميع»!
